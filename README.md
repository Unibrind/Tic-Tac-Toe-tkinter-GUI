# Tic-Tac-Toe

A simple Tic-Tac-Toe game built with Python and Tkinter.

## 🎮 Features

* 3×3 Tic-Tac-Toe board
* Two-player gameplay
* X and O with different colors
* Automatic winner detection
* Draw detection
* Winning combination highlighting
* Turn indicator
* Play Again button
* Modern dark interface

## 🛠️ Technologies

* Python 3
* Tkinter
* Git & GitHub

## ▶️ How to Run

Clone the repository:

`git clone https://github.com/Unibrind/Tic-Tac-Toe-tkinter-GUI.git`

Then run:

`python3 gui.py`
